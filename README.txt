沙巴光伏自备电厂网站 v26 手机版专项优化版

本版基于 v25。电脑版布局与样式保持不变，仅针对手机屏幕（主要 <=650px）优化：
- 顶部品牌/账号操作与横向滑动导航重新排版
- 主页模块改为更适合手机的双列卡片
- 各业务模块链接改为手机触控布局
- 花名册手机版自动改为人员卡片，电脑版仍为表格
- 结构图手机端保持横向滑动
- 管理后台表单、标签页、表格、弹窗适配手机
- 登录页增加手机专项布局和 iPhone 安全区域适配

Cloudflare KV、账号、权限、操作日志、系统设置、备份恢复等数据逻辑未更改。

部署方式与上一版相同：上传 public、src、wrangler.jsonc、README.txt 到 GitHub 后提交。


v27 更新：手机版主内容区域支持左右滑动切换顶部主页面。左滑下一页、右滑上一页；导航、组织结构图、表格、筛选栏和输入区域仍保留各自的横向/输入操作，避免冲突。电脑版不启用此功能。
