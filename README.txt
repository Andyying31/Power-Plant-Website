沙巴光伏自备电厂网站 v26 手机版专项优化版

本版基于 v25。电脑版布局与样式保持不变，仅针对手机屏幕（主要 <=650px）优化：
- 顶部品牌/账号操作与横向滑动导航重新排版
- 主页模块改为更适合手机的双列卡片
- 各业务模块链接改为手机触控布局
- 花名册手机版自动改为人员卡片，电脑版仍为表格
- 结构图手机端保持横向滑动
- 管理后台表单、标签页、表格、弹窗适配手机
- 登录页增加手机专项布局和 iPhone 安全区域适配

Cloudflare KV、账号、权限、操作日志、系统设置、备份恢复等数据逻辑未更改。

部署方式与上一版相同：上传 public、src、wrangler.jsonc、README.txt 到 GitHub 后提交。


v27 更新：手机版主内容区域支持左右滑动切换顶部主页面。左滑下一页、右滑上一页；导航、组织结构图、表格、筛选栏和输入区域仍保留各自的横向/输入操作，避免冲突。电脑版不启用此功能。


=== v28 手机/电脑代码分离 ===
- desktop.css：电脑版界面（保持 v27 电脑版外观不变）
- mobile.css：手机版界面，仅 <=650px 加载
- app.js：账号、权限、后台、数据等双方共用的业务逻辑
- desktop.js：电脑版专属交互入口
- mobile.js：手机版专属交互；包含新的自然滑动切页

手机版滑动优化：
- 手指拖动时页面会跟随移动
- 支持快速轻扫与距离判断
- 松手后使用缓出动画自然进入下一页
- 滑动距离不足时会自然回弹
- 输入框、表格、结构图、筛选区、按钮等区域避免误触换页
- 屏幕边缘保留浏览器返回手势
- 电脑版不启用手机滑动逻辑


v29 新增：
- 全站搜索：模块、内部 Lark 按钮、花名册人员。
- 每个账号独立收藏夹，收藏资料保存在 Cloudflare KV。
- 管理后台主页模块和内部按钮支持鼠标/手指拖拽排序。
- PWA：Android / iPhone 可添加到主屏幕，以独立应用窗口打开。
- PWA 不缓存登录后的业务页面和 API 数据，避免离线缓存敏感资料。
