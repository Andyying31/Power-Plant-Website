沙巴光伏自备电厂网站 v33｜普通链接 + 月份链接｜后台整合版

本版基于 v32，继续保留现有账号、权限、PWA、全站搜索、记住账号/密码，以及手机版连续丝滑滑动。

一、v33 主要调整
1. 内部按钮增加“按钮类型”选择，目前只保留两种：
   - 普通链接
   - 月份链接

2. 普通链接
   - 后台填写一个 https:// 网址
   - 用户点击按钮后直接打开该网址

3. 月份链接
   - 用户点击后先选择年份和月份
   - 再打开对应月份设置的网址
   - 每一个月份链接按钮都有自己独立的年月网址
   - 可新增年份，并分别填写 1-12 月的网址

4. 后台呈现方式调整
   - 已取消原来管理后台单独的“月计划”标签
   - 月份网址直接放进“主页模块 → 内部按钮管理 → 编辑内部按钮”窗口
   - 当按钮类型选“月份链接”时，编辑窗口自动出现“月份网址”区域
   - 当按钮类型选“普通链接”时，只显示普通网址输入框

5. 旧数据兼容
   - 原来的“月计划”按钮会继续保留
   - 原来 Cloudflare KV 中单独保存的月计划年月网址会自动迁移进原来的月计划按钮
   - 升级 v33 不会清空原有账号、花名册、公告、模块、按钮或月计划资料
   - 旧备份恢复到 v33 后，也会继续执行兼容迁移

- 电脑版 / 手机版样式和专属交互分离
- 手机版连续快速左右滑动切页

- 用户自行修改密码
- 记住账号 / 记住密码
- 全站搜索
- PWA 添加到手机桌面
- 花名册与组织结构图
- 共享公告与历史版本

- 完整数据备份 / 恢复
- 模块与内部按钮的上移 / 下移 / 置顶 / 置底排序

三、仍按要求不启用
