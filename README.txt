沙巴光伏自备电厂网站 v20｜主页模块完全后台管理版

本版在 v18 基础上新增：
1. 原“会议”主页模块首次升级时改名为“部门管理例会”。
2. 首次升级自动新增“工艺运行”“维护工作”“化学”三个主页模块。
3. 主页 Dashboard 的模块名称、说明、显示/隐藏和顺序都可在管理后台修改。
4. 顶部导航与主页 Dashboard 共用同一份资料：改名、显示/隐藏、排序会自动同步。
5. 可以随时新增新的主页模块；新增后会自动出现在顶部导航“管理后台”之前。
6. 每一个主页模块都可以管理自己的“内部按钮”：新增、编辑、链接、显示/隐藏、排序、删除。
7. 花名册、共享公告属于特殊模块：名称和位置也能改；进入后原有功能保留，同时可在页面上方增加自己的内部按钮。
8. 原部门管理例会里面已经设置过的会议按钮会自动迁移并保留；月计划年月链接继续沿用原数据。
9. v18 的网站密码、管理员密码、30分钟无操作退出、关闭标签页后重新登录规则全部保留。
10. 花名册、共享公告、公告历史、月计划及其他 Cloudflare KV 数据不会因为本次部署重置。

部署：
把 public、src、wrangler.jsonc、README.txt 上传到原 GitHub 仓库并 Commit。
Cloudflare 会按现有 Worker / KV 配置自动部署。
不需要新建 KV，也不要删除原 SHARED_BOARD 绑定。

管理员后台：
- “主页模块”：管理 Dashboard / 顶部导航，以及每个模块里面的按钮。
- “月计划”：管理年月对应的 Lark 链接。
- “花名册管理”：新增、编辑、删除人员。
- “公告历史”：查看和恢复共享公告历史版本。


v20 更新：仅优化电脑与手机顶部导航栏视觉和交互，不修改后台数据结构与原有业务功能。
