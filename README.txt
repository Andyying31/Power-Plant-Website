沙巴光伏自备电厂网站 v30｜全站搜索 + PWA

本版基于 v28 的“手机 / 电脑代码分离 + 手机版丝滑滑动”架构。

保留功能：
- 电脑版与手机版样式/专属交互继续分离
- 手机版主内容区域左右滑动切页
- 账号登录、权限、修改密码、管理后台
- 首页模块、内部 Lark 按钮、月计划、花名册、共享公告
- 操作日志、系统设置、完整数据备份/恢复

本版新增/保留：
1. 全站搜索
   - 搜索主页模块
   - 搜索各模块内部 Lark 入口
   - 搜索花名册工号、姓名、岗位、职衔等
   - 电脑可点击“全站搜索”，也可按 / 快捷键

2. PWA
   - Android / iPhone 可添加到手机主屏幕
   - 桌面名称：自备电厂
   - 独立窗口打开，更接近 App 使用体验
   - Service Worker 仅缓存 PWA 图标和清单，不缓存登录后的业务页面或 API 数据

按用户要求，本版已取消：
- 收藏夹
- 拖拽排序

排序仍保留原来的“上移 / 下移 / 置顶 / 置底”方式。

Cloudflare KV 原有账号、花名册、公告、模块、按钮、月计划等数据不会因升级本版本而重置。

部署方式：
上传 public、src、wrangler.jsonc、README.txt 和 PWA安装说明.txt 到 GitHub 后提交，Cloudflare 自动部署。
