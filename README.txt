沙巴光伏自备电厂网站 v31｜记住账号/密码 + 全站搜索 + PWA

本版基于 v30，继续保留“手机 / 电脑代码分离 + 手机版丝滑滑动”架构。

保留功能：
- 电脑版与手机版样式/专属交互继续分离
- 手机版主内容区域左右滑动切页
- 账号登录、权限、修改密码、管理后台
- 首页模块、内部 Lark 按钮、月计划、花名册、共享公告
- 操作日志、系统设置、完整数据备份/恢复
- 全站搜索
- PWA 手机桌面安装

本版新增：
1. 登录页增加两个独立勾选项
   - 记住账号
   - 记住密码

2. 保存规则
   - 勾选“记住密码”时会自动同时勾选“记住账号”
   - 只有账号密码验证成功后，才会真正保存本次输入的信息
   - 仅记住账号：下次自动填写用户名，密码仍需输入
   - 记住账号 + 记住密码：下次自动填写用户名和密码
   - 退出登录不会清除已记住的信息
   - 用户自行修改密码后，如果该账号原本勾选了“记住密码”，本机保存的密码会同步更新
   - 取消勾选并成功登录后，会清除对应的已保存信息

3. 保存位置
   - 登录信息只保存在当前手机或电脑的当前浏览器本地
   - 不会写入 Cloudflare KV
   - 不会进入网站完整数据备份
   - 更换设备、清除浏览器网站数据或使用无痕模式后不会保留
   - 不建议在公用电脑或多人共用设备勾选“记住密码”

继续保留：
- 全站搜索：搜索模块、内部 Lark 入口、花名册人员信息
- PWA：Android / iPhone 可添加到手机主屏幕，独立窗口打开
- PWA Service Worker 不缓存登录后的业务页面或 API 数据

按用户要求继续取消：
- 收藏夹
- 拖拽排序

排序仍保留原来的“上移 / 下移 / 置顶 / 置底”方式。

Cloudflare KV 原有账号、花名册、公告、模块、按钮、月计划等数据不会因升级本版本而重置。

部署方式：
上传 public、src、wrangler.jsonc、README.txt 和 PWA安装说明.txt 到 GitHub 后提交，Cloudflare 自动部署。
