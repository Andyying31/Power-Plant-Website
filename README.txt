沙巴光伏自备电厂网站 v33｜普通链接 + 月份链接｜后台整合版

本版基于 v32，继续保留现有账号、权限、PWA、全站搜索、记住账号/密码，以及手机版连续丝滑滑动。

一、v33 主要调整
1. 内部按钮增加“按钮类型”选择，目前只保留两种：
   - 普通链接
   - 月份链接

2. 普通链接
   - 后台填写一个 https:// 网址
   - 用户点击按钮后直接打开该网址

3. 月份链接
   - 用户点击后先选择年份和月份
   - 再打开对应月份设置的网址
   - 每一个月份链接按钮都有自己独立的年月网址
   - 可新增年份，并分别填写 1-12 月的网址

4. 后台呈现方式调整
   - 已取消原来管理后台单独的“月计划”标签
   - 月份网址直接放进“主页模块 → 内部按钮管理 → 编辑内部按钮”窗口
   - 当按钮类型选“月份链接”时，编辑窗口自动出现“月份网址”区域
   - 当按钮类型选“普通链接”时，只显示普通网址输入框

5. 旧数据兼容
   - 原来的“月计划”按钮会继续保留
   - 原来 Cloudflare KV 中单独保存的月计划年月网址会自动迁移进原来的月计划按钮
   - 升级 v33 不会清空原有账号、花名册、公告、模块、按钮或月计划资料
   - 旧备份恢复到 v33 后，也会继续执行兼容迁移

二、继续保留
- 电脑版 / 手机版样式和专属交互分离
- 手机版连续快速左右滑动切页
- 账号登录、普通用户 / 管理员权限
- 用户自行修改密码
- 记住账号 / 记住密码
- 全站搜索
- PWA 添加到手机桌面
- 花名册与组织结构图
- 共享公告与历史版本
- 操作日志
- 系统设置
- 完整数据备份 / 恢复
- 模块与内部按钮的上移 / 下移 / 置顶 / 置底排序

三、仍按要求不启用
- 收藏夹
- 拖拽排序

四、部署
将以下内容覆盖上传到 GitHub 后 Commit：
- public
- src
- wrangler.jsonc
- README.txt
- PWA安装说明.txt
- 登录记住功能说明.txt

Cloudflare 会按现有设置自动部署。


v34 更新：电脑版业务入口卡片改为紧凑布局；大屏默认3列，普通笔记本2列，超宽屏4列；手机版保持不变。


v35 更新：内部按钮新增“年度链接”类型。管理员可为同一个按钮添加多个年份及对应 https:// 网址；前台点击后先选择年份，再打开对应 Lark/网页链接。普通链接和月份链接继续保留。


v36 更新：内部按钮新增“文件夹”类型。前台点击后会打开一个内部文件夹窗口，显示管理员在该文件夹中配置的子按钮；子按钮可设置名称、说明、https:// 链接、显示/隐藏及顺序。文件夹目前限制为一层，不允许继续嵌套文件夹。


v37 更新：优化文件夹子按钮编辑界面，解决网址输入区域拥挤/溢出的问题。文件夹内每个子按钮现在可独立选择“普通链接 / 月份链接 / 年度链接”，月份与年度网址直接在该子按钮的折叠设置区维护；文件夹仍限制一层，不支持子文件夹继续嵌套。
