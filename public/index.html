管理员登录

请输入管理员密码。密码只保存在当前浏览器标签页，不会写入网页代码。

管理后台已登录 修改内容后会直接保存到 Cloudflare。

主页模块管理

主页卡片和顶部导航使用同一份资料。改名称后两边会一起更新；新增模块会自动排在“管理后台”前面。

可用“上移 / 下移 / 置顶 / 置底”调整位置；顶部导航和主页顺序会同步。

内部按钮管理

先从上面的主页模块中选择“管理里面按钮”。

月计划链接管理

这里管理“月计划”年月对应的 Lark 链接。月计划这个内部按钮的名称、说明、显示状态和顺序，请在“主页模块”里进入对应模块管理。

完整数据备份

导出当前 Cloudflare KV 中的全部网站数据。包含花名册、主页模块、内部按钮、月计划、共享公告及历史版本等；不包含网站密码和管理员密码。

备份文件是一个 JSON 文件，请妥善保存。以后更换 Cloudflare、重建 KV 或迁移服务器时，可以用它恢复网站资料。

恢复完整备份

选择之前导出的备份文件。恢复会覆盖备份文件中同名的云端数据，恢复完成后网站会自动刷新。
